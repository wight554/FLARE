<objective>
Replace the type-P urgent-refill snap with a bounded, rail-relative, slew-limited relief feed, and prove
in `flare_sim` — at three rail scales — that no path commands the raw clamped max step rate while the
buffer is pegged at tension. This is Phase 13 Success Criterion 1 plus the ROADMAP carried caveat, and it
is the tracer slice for the whole phase: it wires one behaviour through every layer Phase 13 touches
(config.ini -> gen_config -> tune.h -> main.c global -> TLV persistence -> `SET:`/`GET:` -> control loop ->
`EV:` events -> sim scenario -> docs), so plans 02 and 03 expand out from a proven spine rather than
discovering a layering problem after three commits.

Purpose: eliminate the "snap to compression rail -> RELIEF_PAUSE -> restart" hunting cycle captured in
`13-.../baseline-capture.md` (2.4-3.4 s cadence, dozens of cycles in 111 s), without repeating the
`51bdca8` mistake of gating a type-P behaviour on an absolute normalized-position literal.
Output: bounded relief live in `sync.c`, `SYNC_PSF_RELIEF_MULT` as a live + flash-persisted knob, three new
sim scenarios, the six phase REQ IDs registered.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host `SET:` over USB CDC → `protocol.c` parameter handler | Any process with the serial port open (or Moonraker write access to the FLARE daemon fronting it) can set the new relief multiplier at runtime. Single-client serial device, no firmware-layer auth concept; daemon-layer auth is Phase 9's scope. |
| Flash TLV record → `settings_load_tlv_tag()` | A persisted settings sector written by a different firmware build (or corrupted) is parsed at boot; a duplicate or mis-sized tag silently overwrites an unrelated field. |
| Plant/ADC reading → `g_buf_pos` → relief trigger | The normalized buffer reading is uncalibrated per rig; a threshold derived from it can silently disable a safety behaviour on a rig whose rail reads shallow (the `51bdca8` failure mode). |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
