# Plan 11-01: Firmware Forensics & Main Loop Jitter Instrumentation

**Goal**: Implement uninitialized RAM blackbox crash logging surviving watchdog resets, line-by-line post-mortem retrieval, and high-resolution main-loop execution jitter instrumentation.

## Requirements
- `REQ-forensics-retention-ram`: Circular 32-entry blackbox in `__uninitialized_ram` validated via magic cookie (`0x43525348`) and CRC32 checksum.
- `REQ-forensics-event-sampling`: State machine transitions + 100ms breadcrumb snapshots capturing active lane, tasks, buffer position, motor rates, and sensor mask.
- `REQ-forensics-watchdog-signal`: On boot following watchdog reboot with valid crash signature, emit `EV:CRASH:DETECTED:WATCHDOG`.
- `REQ-forensics-protocol`: `GET:CRASHLOG` streaming indexed lines; `CAL:CRASHLOG_CLEAR` buffer reset.
- `REQ-loop-jitter-telemetry`: High-resolution `time_us_32()` benchmarking measuring loop period, module peaks, `GET:LOOP_STATS`, and `EV:WARN:LOOP_LAG` warning at > 15ms.
- `REQ-forensics-host-sim`: Host simulation coverage in `tests/host/test_forensics.c` validating crash capture, retrieval, and jitter tracking.

## Success Criteria
1. Blackbox buffer retains last 32 transitions/breadcrumbs without writing to flash.
2. Simulated watchdog reset preserves crash buffer, emits `EV:CRASH:DETECTED:WATCHDOG` on boot, and provides complete pre-crash event history.
3. `GET:CRASHLOG` streams chronological lines from oldest to newest with termination `OK:CRASH:END`.
4. `CAL:CRASHLOG_CLEAR` invalidates signature and clears buffer cleanly.
5. `GET:LOOP_STATS` reports current, max, avg loop time ($\mu\text{s}$), overruns, and top culprit module.
6. Loop lag exceeding 15ms emits `EV:WARN:LOOP_LAG:<us>:<module>`.
7. `ninja -C build_local`, `ninja -C build_sim`, and `python3 scripts/validate_regression.py` pass 100%.
