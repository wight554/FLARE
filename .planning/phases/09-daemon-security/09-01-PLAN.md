# Phase 9: Daemon Security & Remote Command Hardening — Plan (09-01-PLAN.md)

## Goal
Implement bearer token authentication, loopback exemption, per-client token-bucket rate limiting on serial commands, and WebUI/CLI token integration for `flare_daemon.py` and `flare_cmd.py`.

## Proposed Changes

### 1. `scripts/flare_daemon.py`
- Add TokenBucket rate limiter helper class with idle bucket expiration.
- Add auth token initialization function (`init_auth_token(args)`):
  - Check `--auth-token` arg, then `FLARE_AUTH_TOKEN` env, then `~/.flare/auth.token`.
  - If bound to non-loopback and no token present, generate 16-byte hex token, write `~/.flare/auth.token` with `chmod 0600`.
- Add `--auth-token` and `--trust-proxy` command line arguments to `argparse`.
- In `FlareHTTPHandler`:
  - Determine client IP via `self.client_address[0]` (or `X-Forwarded-For` if `--trust-proxy`).
  - Helper `is_loopback(ip)` returning True for `127.0.0.1`, `::1`, `localhost`.
  - Helper `is_authenticated()` verifying Bearer token against active auth token if not loopback.
  - In `do_POST`:
    - Check rate limit on `self.path == "/cmd"`. Return 429 if exceeded.
    - Check `is_authenticated()` for `/cmd`, `/config`, `/gatemap`. Return 401 if unauthorized.

### 2. `scripts/flare_cmd.py`
- Add `--api-host` (default: `127.0.0.1` or `FLARE_API_HOST`) and `--auth-token` (or `FLARE_AUTH_TOKEN` or `~/.flare/auth.token`).
- In `send_daemon_cmd` and `get_daemon_status`:
  - Build URL with configured host & port.
  - Inject `Authorization: Bearer <token>` when targeting non-loopback host or when token is configured.

### 3. `scripts/webui/app.js` and `scripts/webui/index.html`
- In `app.js`:
  - Read `localStorage.getItem('flare_api_token')`.
  - Attach `Authorization: Bearer ${token}` to `fetch('/cmd')` and `fetch('/gatemap')`.
  - If 401 received, trigger API Key modal prompt, store result, and allow retry.
  - Provide a key button/modal to configure API token.
- In `index.html`:
  - Add API Key button/modal to UI header.

### 4. `scripts/test_flare_daemon_security.py`
- Add unit test suite testing:
  - Token generation & file permissions (`0600`).
  - Loopback authentication exemption.
  - Remote unauthenticated GET (200).
  - Remote unauthenticated POST (401).
  - Remote valid token POST (200).
  - Remote invalid token POST (401).
  - Rate limiting burst & replenishment (429).
  - Rate limiting loopback exemption.
  - Anti-spoofing `X-Forwarded-For` behavior.

### 5. Documentation
- Update `MANUAL.md` with new daemon security flags, token behavior, and `flare_cmd.py` options.
