## Decision D12.1 — daemon bind host (supersedes audit-hardening-fixes 4.1 and 38de2a7)
Default `--host 0.0.0.0` again. 4.1 reverted the loopback default on 2026-06-19 because it silently
removed the LAN dashboard on reinstall; 38de2a7 re-introduced loopback for security before Phase 9
existed. With Phase 9 in place a LAN bind is safe: loopback peers stay exempt, remote mutations need
the auto-generated Bearer token, reads stay public. `--trust-proxy` now forces `AUTH_REQUIRED`
regardless of bind host (behind nginx the peer is always loopback). Operators who want loopback-only
add `--host 127.0.0.1` to the unit; `install_daemon.py` preserves it.
