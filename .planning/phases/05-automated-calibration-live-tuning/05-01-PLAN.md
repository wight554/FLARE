# Plan 05-01: Automated Sensor Calibration & Live Tuning Enhancements

**Goal**: Deliver deterministic Type-P ADC sensor calibration wizard, USB CDC live tuner PSF gain adjustments, and trace analyzer step-rate vs displacement charting.

## Requirements
- `REQ-calibration-workflow`: Evidence collection without mutation unless explicit write flag provided; deterministic derivation.
- `REQ-live-tuner`: Live adjustment and observation of sync and PSF parameters over serial.
- `REQ-analyzer-rigor`: Log conversion to step-rate vs displacement charts and robust validation.

## Success Criteria
1. Calibration wizard measures and sets Type-P ADC thresholds automatically (`scripts/flare_calibrate.py`).
2. Live tuner CLI allows adjusting PSF proportional gains over USB CDC (`scripts/flare_live_tuner.py`).
3. Trace analyzer converts raw logs into step-rate vs buffer displacement charts (`scripts/flare_analyze.py --chart`).
4. Full regression suite passes (`ninja -C build_local`, `validate_regression.py`, `ruff`).
