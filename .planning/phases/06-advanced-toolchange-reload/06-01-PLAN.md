# Plan 06-01: Advanced Toolchange, Cutter Hardening, and Bypass Automation

**Goal**: Implement cutter watchdog and servo interlocks, toolhead load retries and extruder gear parking, firmware-enforced external spool bypass, and Klipper pause escalation.

## Requirements
- `REQ-toolchange-orchestration`: Toolhead clear, cutter watchdog, retry sequencing, and phase event emission.
- `REQ-cutter-feed-timeout`: Servo protection on failure, interlock against mid-cut `CP` test commands.
- `REQ-filament-bypass`: Firmware and Klipper external spool bypass semantics, locking MMU steppers, disabling sync, and masking lane sensors.

## Success Criteria
1. `CP` command is rejected with `ER:BUSY:CUTTER` while cutter is busy.
2. Cutter timeout or failure de-energizes servo PWM (`servo_idle`) to prevent burnout, halts motor feed, and escalates to `TC:ERROR`.
3. Toolchange loading implements up to `tc_ts_retries` retract-and-advance cycles on missing `TS:1`, and feeds `tc_ts_park_mm` on detection before `TC_LOAD_DONE`.
4. Firmware exposes `SET:BYPASS 1/0` / `GET:BYPASS`; when active, lane motions are rejected with `ER:BYPASS_ACTIVE`, sync is suspended, and lane runout triggers are masked.
5. `klipper/mmu.py` `cmd_MMU_PAUSE` dispatches `STOP` to FLARE over serial.
6. Local build (`ninja -C build_local`), python scripts compile (`py_compile`), and regression validation pass.
