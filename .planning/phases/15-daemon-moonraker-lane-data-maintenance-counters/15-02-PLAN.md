  <action>
    In `scripts/flare_daemon.py`:
    1. Update `db_init()` to create `maintenance_counters` table:
       `CREATE TABLE IF NOT EXISTS maintenance_counters (name TEXT PRIMARY KEY, count INTEGER NOT NULL DEFAULT 0, limit_val INTEGER, warning TEXT, pause INTEGER NOT NULL DEFAULT 0, last_reset TEXT);`
       Auto-seed default rows if empty:
       - `cutter_cuts`: limit_val=1000, warning="Cutter blade wear limit reached. Replace blade and reset counter.", pause=0
       - `swaps`: limit_val=None, warning="", pause=0
       - `reload_failovers`: limit_val=None, warning="", pause=0
    2. Add CRUD helper functions:
       - `get_maintenance_counters()`: returns dict of all counters.
       - `update_maintenance_counter(name, incr=0, limit_val=None, warning=None, pause=None, reset=False, delete=False)`:
         Atomically updates counter state in DB and checks thresholds.
    3. Update `record_event_stats(evt_type, evt_data)`:
       - On `EV:CUT:DONE`: call `update_maintenance_counter('cutter_cuts', incr=1)`.
       - On `TC:DONE`: call `update_maintenance_counter('swaps', incr=1)`.
       - On `EV:RELOAD:*` or reload trigger: call `update_maintenance_counter('reload_failovers', incr=1)`.
    4. Threshold escalation logic:
       - When `count >= limit_val`:
         - Set warning flag in `status_cache["maintenance"]["warnings"]`.
         - Emit console notice via Moonraker `/printer/gcode/script` (`M118 FLARE WARNING: <warning>`).
         - If `pause == 1` and not already triggered in current print session, call Klipper `PAUSE`.
    5. Expose HTTP endpoints in daemon:
       - `GET /maintenance`: returns JSON dict of all counters.
       - `POST /maintenance`: accepts `{action: "update"|"reset"|"delete", name: str, ...}`.
       - Expose `maintenance` summary in `/status`.
  </action>

    <automated>python3 -c "import scripts.flare_daemon as fd; fd.db_init(); c = fd.get_maintenance_counters(); assert 'cutter_cuts' in c; print('COUNTERS_INIT_OK')"</automated>
    <fails_when>Database initialization fails, table missing, or syntax error</fails_when>
  </verify>
