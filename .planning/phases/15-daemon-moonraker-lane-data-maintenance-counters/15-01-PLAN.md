    1. Define `build_moonraker_lane_payload(gate_idx)`:
       - Retrieve gate map information via `_read_gate_map()` and Spoolman data via `_spoolman_get_spool(spool_id)`.
       - Extract:
         - `vendor_name`: spool['filament']['vendor']['name'] if available else ""
         - `name`: spool['filament']['name'] if available else gm['gate_name'][gate_idx]
         - `color`: (spool['filament'].get('color_hex') or gm['gate_color'][gate_idx]).lstrip("#")[:6].upper()
         - `material`: spool['filament'].get('material') or gm['gate_material'][gate_idx]
         - `bed_temp`: int(spool['filament'].get('settings_bed_temp') or 0)
         - `nozzle_temp`: int(spool['filament'].get('settings_extruder_temp') or 0)
         - `scan_time`: current epoch timestamp float
         - `td`: float(spool.get('extra', {}).get('transmission_distance') or 0.0)
         - `lane`: int(gate_idx)
         - `spool_id`: int(gm['gate_spool_id'][gate_idx])
         - `filament_id`: int(spool['filament']['id']) if spool and 'filament' in spool and 'id' in spool['filament'] else -1
       - Return JSON-serializable dictionary.
    2. Implement `_moonraker_db_post_item(namespace, key, value)` and `_moonraker_db_delete_item(namespace, key)`:
       - `POST /server/database/item` with query/body `{"namespace": namespace, "key": key, "value": value}`.
       - `DELETE /server/database/item?namespace=...&key=...`.
       - Catch `urllib.error.URLError`, `http.client.HTTPException`, `TimeoutError`, log debug warnings without raising.
    3. Implement background queue worker `_moonraker_sync_worker` and `trigger_moonraker_lane_data_sync()`:
       - Thread-safe queue ensures DB HTTP calls do not block the main or serial reader threads.
       - Deduplicates pending sync requests.
