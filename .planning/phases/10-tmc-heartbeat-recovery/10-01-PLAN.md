# Plan 10-01: TMC2209 Register Heartbeat & Auto-Recovery

**Goal**: Implement continuous idle-loop TMC2209 CHOPCONF register sentinel verification, automatic reconfiguration on brownout recovery, strict motion lockout to guarantee zero step jitter, wire protocol events, ST: telemetry, and host simulation test coverage.

## Requirements
- `REQ-tmc-heartbeat`: Idle-loop sentinel polling on `CHOPCONF` (`0x6C`) matching cached `tmc->chopconf`.
- `REQ-tmc-motion-lockout`: Strict idle lockout (`controller_activity_in_progress() == false`); zero UART reads during active motion, sync control, or cutting.
- `REQ-tmc-recovery-escalation`: 3 re-apply retries with 50ms backoff. On success: `EV:TMC:RESTORED:<lane>`. On exhaustion: `stop_all()`, `EV:TMC:FAULT:<lane>:COMM_FAIL` (escalating to Klipper pause).
- `REQ-tmc-telemetry`: `TMC:<l1><l2>` health flags in `ST:` / `?:` status dumps; host daemon mirrors state.
- `REQ-tmc-host-sim`: Stateful register mock and fault injection in host test suite (`tests/host/test_tmc_recovery.c`).

## Success Criteria
1. `CHOPCONF` sentinel check runs at 1000ms cadence in main loop, alternating lanes (L1 at $t=0$, L2 at $t=1\text{s}$).
2. Heartbeat strictly halts when `controller_activity_in_progress()` is true (lane busy, sync active, cutter busy, boot stabilizing, manual unload).
3. Brownout (simulated by resetting mock CHOPCONF to silicon default `0x10000053`) triggers `sync_tmc_settings()` re-apply, verifies readback, emits `EV:TMC:RESTORED:<lane>`, and keeps health flag `1`.
4. Persistent UART failure halts all motion via `stop_all()`, sets health flag `0`, and emits `EV:TMC:FAULT:<lane>:COMM_FAIL`.
5. Status line includes `TMC:<l1_health><l2_health>` and `flare_daemon.py` parses `tmc_health`.
6. `tests/host/test_tmc_recovery.c` compiles and passes all test assertions in host simulation.
7. `ninja -C build_local`, host tests, and `python3 scripts/validate_regression.py` pass 100%.
